# v0.27.0 — Real Communication Integrations

## Что добавлено
- Telegram Bot API outbound + webhook inbound.
- VK Messages API outbound + callback inbound.
- WhatsApp Cloud API outbound + webhook verification/inbound.
- Conversation threads и единая история коммуникаций.
- Provider message IDs и idempotency для входящих webhook-сообщений.
- Автоматическая классификация входящих ответов: CONTACTED / INTERESTED / NEGOTIATION / LOST.
- Простая защита do-not-contact через metadata контакта.
- Timeline коммуникаций в Lead Workspace.
- Исправлен API base URL фронтенда на `/api/v1`.

## Важно
Провайдеры включаются только при наличии официальных credentials и соблюдении правил соответствующей платформы. Webhook secrets обязательны для Telegram/VK.

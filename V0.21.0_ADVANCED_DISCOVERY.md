# v0.21.0 — Advanced Discovery + Query Builder

## Что добавлено

- Typed Discovery Filter AST in `packages/shared`.
- AND/OR Query Builder in the web app.
- City/category discovery options from PostgreSQL.
- Boolean, text, numeric and grade filters.
- Search jobs persist the complete filter definition in `search_jobs.filters`.
- Worker evaluates structured filters before persisting/enriching a raw lead.
- Search UI shows a human-readable query preview.
- Supported fields: city, category, website, phone, email, Telegram, VK, WhatsApp, Instagram, online booking, technology, rating, reviews, employees, lead score, grade.

## Example

`Category = BEAUTY_SALON AND City = Москва AND Has Website = true AND Rating >= 4.5 AND Reviews >= 100`

or

`Telegram = true OR VK = true`

## Important

The filter schema is designed to be extended with nested groups in the next iterations. Enrichment-dependent fields are evaluated against the data available to the source at search time; the later enrichment pipeline remains the source of truth for website intelligence.

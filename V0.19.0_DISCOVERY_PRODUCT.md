# v0.19.0 — Discovery Product Pipeline

## Goal
Turn the technical crawler into a visible product workflow: Search → Crawl → Website Intelligence → Score → CRM.

## Backend
- Added authenticated `GET /api/v1/discovery/overview`.
- Tenant-scoped aggregate counters for businesses, leads, HOT/WARM leads, active searches and crawls.
- Search worker now automatically creates a persisted crawl job for discovered websites and enqueues URL jobs into BullMQ.
- Search results therefore flow into browser crawling without a manual second step.

## Frontend
- Added `/discovery` product page.
- Live polling every 3 seconds for pipeline progress.
- Added totals for companies, qualified leads, HOT and WARM leads.
- Added crawl progress and active job counters.
- Added recent searches and CTA to start a new search.
- Added Discovery to the main navigation.

## Product workflow
1. User creates a search.
2. Search worker collects raw businesses.
3. Websites are collected from the search result.
4. A crawl job is persisted.
5. BullMQ schedules browser crawling.
6. Crawl persistence creates/updates business, contacts, website analysis, features, score and CRM lead.
7. Discovery UI exposes the resulting pipeline state.

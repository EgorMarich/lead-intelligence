# v0.28.0 — AI Reply Copilot

Lead Intelligence now turns inbound replies into an actionable sales loop.

## Added
- AI reply suggestions based on the latest inbound message.
- Intent/sentiment/recommended-action classification.
- OpenAI-compatible provider with deterministic fallback.
- Editable reply before sending.
- One-click use of a suggestion through the existing Outreach/BullMQ pipeline.
- Suggested/used/dismissed state persisted in PostgreSQL.
- Outbound messages continue to appear in the unified Communication Timeline.
- Lead status is still updated from inbound classification.

## Flow
`Inbound reply → AI analysis → editable suggestion → human approval → Outreach queue → provider → Communication Timeline`

The copilot does not auto-send AI replies. A user explicitly confirms the final text before it enters the send queue.

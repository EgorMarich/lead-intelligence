# v0.31.0 — Sales Command Center

## Goal
Create a single operational dashboard for sales teams: what is hot, what requires action now, what AI prepared, and which automated sequences are due.

## Backend
- `GET /api/v1/command-center/overview`
- Tenant-scoped and permission-protected.
- Aggregates hot leads, active sequence enrollments, inbound replies and pending AI decisions.
- Produces a prioritized action queue.
- No new database tables; reuses existing CRM, communication, sequence and AI decision data.

## Frontend
- New `/command-center` page.
- KPI cards, prioritized action queue, hot leads, recent replies and active sequences.
- Refreshes automatically every 30 seconds.

## Safety
- The dashboard never sends a message by itself.
- It surfaces actions for the existing provider/outreach pipeline.
- Existing opt-out and CRM stop conditions remain authoritative.

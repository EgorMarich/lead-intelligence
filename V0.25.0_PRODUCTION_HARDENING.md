# v0.25.0 — Production Hardening & Deploy

## Added

- Production Dockerfiles for API, worker and Next.js web.
- Docker Compose stack: PostgreSQL, Redis, migrations, API, worker and web.
- Health checks for PostgreSQL, Redis, API and worker.
- Worker HTTP health endpoint on port 3001.
- API database/Redis health verification.
- Graceful Nest shutdown hooks and worker SIGINT/SIGTERM shutdown.
- Strict global DTO validation (`forbidNonWhitelisted`).
- Configurable CORS origin.
- Production environment template.
- Deployment and backup runbook.
- Restart policies and persistent Redis AOF/Postgres volumes.
- Standalone Next.js production build.
- Structured startup/fatal logs.

## Operational flow

`docker compose up --build` → Postgres/Redis healthy → migrations → API/worker healthy → web.

Migrations are intentionally a separate one-shot service so the application containers do not mutate schema during every restart.

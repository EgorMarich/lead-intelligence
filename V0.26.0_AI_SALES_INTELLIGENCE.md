# v0.26.0 — AI Sales Intelligence

## Goal
Turn enriched lead data into actionable sales intelligence: ICP fit, pain points, pitch, recommended channels, objection handling, next-best action and outreach variants.

## API
- `GET /api/v1/ai-intelligence/:businessId`
- `POST /api/v1/ai-intelligence/:businessId/analyze`

## Providers
The service works without an external provider using a deterministic heuristic fallback. For an OpenAI-compatible provider set `AI_ENABLED=true`, `AI_API_URL`, `AI_API_KEY` and `AI_MODEL`.

The provider is intentionally abstracted behind the service so a future local model or another OpenAI-compatible gateway can be added without changing the UI/API contract.

## Persistence
`ai_insights` stores one current insight per organization/business. Generation is also written to the lead activity timeline as `AI_ANALYSIS_GENERATED`.

## Safety
The prompt explicitly asks the model not to invent facts. Provider failures fall back to heuristics and never mark an analysis as provider-generated when the external call failed.

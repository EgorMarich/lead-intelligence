# v0.8.0 — Lead Intelligence

## Backend

Search results are now promoted from `raw_leads` into organization-scoped `businesses` and automatically enriched with:

- lead score (0–100)
- HOT/WARM/COLD/LOW grade
- scoring reasons
- detected website
- phone/email contacts
- detected Telegram/VK/WhatsApp/online-booking features when present in source payload

New API:

- `GET /api/lead-intelligence`
- `GET /api/lead-intelligence/:id`

All endpoints require JWT and organization context and are protected by `SEARCH_READ`.

## Frontend v0.2

The Leads screen now uses qualified businesses instead of raw scraping records and supports:

- city filter
- minimum score filter
- grade filter
- score display
- rating/review count
- website shortcut

## Important production note

The current v0.8 enrichment intentionally does not fetch arbitrary websites from the API/worker. Before enabling live website analysis, add an SSRF-safe fetcher with DNS/IP validation, redirects policy, timeouts, robots/rate-limit policy and isolated parsing.

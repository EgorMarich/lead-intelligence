# v0.23.0 — Outreach Engine

Lead Intelligence now supports outreach drafts, templates, channel selection and queued sending.

## Channels
EMAIL is sendable when SMTP is configured. Telegram/VK/WhatsApp/Instagram/PHONE are prepared for provider integrations and currently fail safely instead of pretending a message was sent.

## Flow
Lead → contact → personalized preview → draft → queue → provider → SENT/FAILED → CRM activity + CONTACTED status.

## SMTP
Configure `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`.

## API
- GET `/api/v1/outreach/messages`
- GET `/api/v1/outreach/messages/:businessId`
- GET `/api/v1/outreach/preview/:businessId/:channel`
- POST `/api/v1/outreach/messages/:businessId`
- POST `/api/v1/outreach/messages/:id/send`
- GET `/api/v1/outreach/templates`
- POST `/api/v1/outreach/templates`

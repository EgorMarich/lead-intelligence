# v0.34.0 — Product Polish

## Goal
Finalize the product experience without adding new backend business features.

## Design direction
- Modern dark SaaS interface
- Bright lime accent with restrained violet/cyan secondary colors
- Smaller corner radii and sharper component geometry
- No glow effects
- No box shadows
- Minimal visual noise
- High contrast and clear hierarchy
- Pixel font (`Press Start 2P`) used selectively for brand/metrics/headline accents
- Inter remains the primary UI font for readability

## UX polish
- Unified buttons, inputs, panels, navigation and badges
- Stronger hover/focus states
- More consistent spacing and borders
- Responsive layouts preserved
- Language switcher integrated into the app shell

## Scope
This release is intentionally UI/UX focused. Existing backend functionality from v0.33 remains unchanged.

# v0.32.0 — AI Sales Manager

AI layer above Sales Command Center. The manager briefing analyzes CRM leads, inbound replies, stale leads, active sequences and channel activity, then produces a prioritized daily action list, opportunities, risks and manager advice.

## API
- `GET /api/v1/ai-sales-manager/briefing`
- Tenant scoped and protected by `business:read`.

## AI
Uses the existing OpenAI-compatible environment (`AI_ENABLED`, `AI_API_URL`, `AI_API_KEY`, `AI_MODEL`). If unavailable, deterministic heuristic fallback is returned.

## UI
Sales Center now contains an AI Sales Manager panel with priorities, risks, opportunities, KPIs and unanswered replies. It refreshes every 60 seconds and never sends messages automatically.

## Important
No new database tables or migrations. This version reuses existing CRM/communication/sequence data.

# v0.20.0 — Lead Workspace

Lead Intelligence now has a dedicated lead workspace. Qualified businesses can be opened from `/leads`, inspected in a full detail page, moved through CRM statuses, and enriched with team notes.

## API
- `GET /api/v1/lead-intelligence/:businessId` now includes the persistent CRM lead.
- `PUT /api/v1/lead-intelligence/:businessId/crm` updates status, assignee and tags.
- `POST /api/v1/lead-intelligence/:businessId/crm/notes` appends a note and activity.
- Lead persistence adds `notes` and `activities` JSONB columns.

## Frontend
- `/leads` rows link to `/leads/:businessId`.
- Lead Workspace shows score reasons, missed opportunities, contacts, website features, status controls, company facts, social contacts and notes.

## Migration
Run `pnpm --filter @lead/api migration:run` before using the new CRM fields.

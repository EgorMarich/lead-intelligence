# Lead Intelligence v0.30.0 — AI Sales Automation

## Goal
Turn static follow-up sequences into adaptive sales automation. A sequence can now ask the AI what the next best action should be before every outbound step.

## Adaptive decision loop
1. Load lead, company, contacts, latest inbound/outbound communication and AI sales intelligence.
2. Check CRM stop statuses, inbound replies and do-not-contact before any AI decision.
3. AI chooses an allowed channel, writes a personalized message, selects the next delay and recommends the next action.
4. Explicit opt-out stops the enrollment.
5. If AI confidence is below the configured threshold, the worker falls back to the static sequence step.
6. The outbound message is sent through the existing provider pipeline.
7. The next sequence step is scheduled using the AI-selected delay.

## Configuration
`SalesSequenceEntity` adds:
- `automationMode`: `STATIC` or `AI_ADAPTIVE`
- `aiEnabled`
- `aiAllowedChannels`
- `aiMinConfidence`
- `aiDefaultDelayMinutes`
- `aiMaxDelayMinutes`

## Persistence
`ai_sales_decisions` stores the generated decision, provider, confidence, action, body, selected channel and delivery status.

## Safety
- No send occurs before enrollment in a sequence.
- Existing stop statuses take precedence over AI.
- Explicit opt-out is treated as a hard stop.
- Contact `doNotContact` is enforced by the worker.
- AI is instructed not to invent facts or contact details.
- Low-confidence AI output falls back to the configured static step.

## API
- `POST /api/v1/sequences/:id/ai-preview/:businessId` previews the first adaptive decision without sending anything.

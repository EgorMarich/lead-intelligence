# Lead Intelligence v0.22.0 — Automatic Enrichment

v0.22 turns website crawling into a reusable enrichment pipeline.

## What changed

- Added persistent `enrichment_jobs` with tenant isolation.
- Added enrichment lifecycle on businesses: `PENDING → QUEUED → RUNNING → COMPLETED/FAILED`.
- Added `POST /api/v1/enrichment/:businessId` to re-run enrichment for a company.
- Added `GET /api/v1/enrichment/:businessId` for enrichment state and last result.
- Added BullMQ `enrichment.queue` worker with configurable `ENRICHMENT_CONCURRENCY`.
- Reuses the SSRF-safe Puppeteer crawler.
- Detects and persists:
  - emails and phones
  - Telegram, VK, WhatsApp, Instagram
  - online booking
  - contact page
  - analytics
  - ecommerce
  - detected technologies
  - website metadata
- Recalculates lead score and synchronizes the persistent Lead.
- Existing crawl pipeline now marks businesses as enriched and stores technology features.
- Lead Workspace now exposes enrichment status and a manual “Обновить данные” action.

## Environment

`ENRICHMENT_CONCURRENCY=2` controls concurrent enrichment browser jobs.

## Migration

Run TypeORM migration `1710000008000-AutomaticEnrichment` after v0.21 migrations.
